# Contributing to TWYS

Thanks for taking an interest in TWYS.

**Before opening a pull request:** open an issue describing the bug or improvement. Keep changes focused and explain the effect on source attribution, user data, and Windows packaging.

Requirements:
1. Do not submit personal journals, credentials, screenshots, or tokens.
2. Keep market statistics accurately attributed; never insert demo numbers into live market views.
3. Keep data storage non-destructive across upgrades.
4. Run `python -m pytest -q` and note any Windows-specific behavior that could not be tested.
5. Avoid changes that would turn TWYS into a broker or execution platform without an explicit product decision.

Read access to this repository does not itself grant rights to redistribute the software; contributions are subject to project maintainer review.
