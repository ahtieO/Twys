## To finish GitHub setup

1. Visit `github.com/settings/profile`, edit Name/Bio/Company, leave the profile photo unchanged, then save.
2. On the TWYS repository, choose the About-panel gear icon and apply the description and topics.
3. In repository Settings → General → Danger Zone, choose **Change visibility → Public** after verifying the contents and history contain no private data or secrets.
4. Publish the tested `TWYS-Setup.exe` as a **GitHub Release v1.0.0**, with checksum and the public release notes from CHANGELOG.md.
5. Pin the TWYS repository on your profile.

Important: making a repository public exposes its **entire Git history**, not only the files currently visible. Review old commits and rotate any previously committed keys before publishing.
